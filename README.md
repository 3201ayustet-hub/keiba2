# Horse Bet Battle v4.3

v4.2をベースに、順位推移の不具合修正、ヘッダー簡素化、
設定画面のデザイン統一、複数大会運用の導線強化を行った版です。

## v4.3変更点

### 順位推移
- v4.2で線とポイントが黒くなる不具合を修正
- 原因：新しい勝負服データの `bodyColor` への移行に、順位推移だけ旧 `.color` 参照が残っていた
- グラフ線・ポイント・右端参加者ラベルを勝負服の胴色に連動
- 凡例を色丸から小さな騎手勝負服SVGへ変更

### ヘッダー
- HBB表記を削除
- RACE MEETING表記も削除
- 「2026年 秋競馬」のような大会名そのものをロゴ風に表示
- 日付だけを補助情報として表示

### 設定 / 開催管理
- 「勝負の基本情報」フォームをTOPと同じ黒・細罫線・青灰・限定ゴールドに統一
- 勝負名 → 大会名
- 開始日 / 終了日を開催情報として整理
- ルール・賞品・連絡事項を独立セクション化
- キーボード表示中も保存ボタンへ到達できる下部固定操作を維持

### 次シーズン対応
このアプリは複数大会を保存できます。
v4.3では導線を明確化しました。

- 大会一覧から「＋ 新大会」
- 管理画面から「次大会を作成」
- 2026年 秋競馬を残したまま、2027年 春競馬を別大会として作成可能
- 大会一覧で「開催中 / 次回開催 / 終了」を自動表示
- 過去大会へ切り替えて成績を確認可能
