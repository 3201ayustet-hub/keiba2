# Horse Bet Battle v4.4

管理画面をスマホ向けの高密度UIへ変更した版です。

## 変更点
- 新大会作成は大会一覧右上の「＋新大会」だけに統一
- ヘッダーの旧「＋新しい勝負」は非表示
- 管理画面の「次大会を作成」は削除
- 開催設定：大会名1行、開始日/終了日2列、ルール類は折りたたみ
- 参加者設定：勝負服プレビュー小型化、胴/袖/柄色を1行3列、HEXコード削除
- 胴柄/袖柄を1行2列、クイックカラーは折りたたみ
- レース追加/編集：レース名1行、開催日/競馬場と格/距離をコンパクト配置
- 保存/削除/閉じるを小型固定フッターに統一
- v4.3の順位推移修正、勝負服SVG、複数大会対応は維持

Supabase構造変更なし。SQL再実行不要です。
