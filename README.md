# KEIBA QUIZ v11

## 今回の更新
- 通常問題を「意外な特徴」「騎手」「海外遠征」「長寿」「距離レンジ」「芝・ダート」などへ拡張
- 通常問題は1プレイ5問
- 回答後のみ NEXT → を表示
- 正解は○、不正解は×。不正解時に正解肢は表示しない
- FINALは10問
- FINALのヒント順: TIME → 4TH/5TH → 3RD → 2ND → VENUE
- FINALではレース名を表示しない
- 最終回答のみが結果判定対象
- iPhoneホーム画面用manifest/iconを同梱

## 問題DB
questions.json を更新するだけで通常問題を追加できます。
final_races.json を更新するだけでFINALを追加できます。

## 注意
特徴問題は、答えの一意性を確認できるデータを元に追加してください。
特に「未騎乗」「全G1で異なる騎手」「総賞金閾値」などは全キャリアを検証してから公開問題にしてください。

## v12 fixes
- 通常問題は毎プレイ5問をランダム抽出
- 選択肢も毎問ランダム配置
- DB上の正解位置も均等分散
- 不正解時に正解選択肢を表示しない
- FINALは固定5段階ヒントのみ
- FINALに追加のヒント機能や余計な選択機能を追加していない
