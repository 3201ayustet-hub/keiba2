# Horse Bet Battle v4.1

GitHub Pages + Supabase で動作する共有版の競馬馬券勝負アプリです。

## v4.1 のテーマ

v4.0で追加した「競馬場の情報盤」らしさを残しながら、
スマホでの読みやすさを最優先に再整理しました。

### TOP
- 最上部の大きな「馬券勝負ボード」表示を勝負画面では非表示
- 最大払戻額を主役にしたシンプルな着順掲示板
- 回収率の巨大パネルを撤去
- 「順位推移を見る」「回収率を見る」をサブ機能として配置
- 全レースを日付順で常時表示
- レース一覧は「日付 / 競馬場 / G1・非G1 / レース名」に限定
- 距離はトップ一覧から除外
- 参加者一覧は登録順で表示し、勝負服・権利残数・回収率をコンパクト表示
- 非G1のみの回収額などの追加統計は表示しない
- 下部ナビ TOP / RACES / PLAYERS / RANK / 管理 を維持

### RANK
- 最大20レース対応
- 開いた直後は直近5レース
- 左スワイプで過去へ
- 右端参加者ラベル、ポイント詳細、首位交代履歴を維持
- TOPと同じ黒・細罫線ベースへデザイン統一

### RETURN RATE
- トップから分離した参考成績画面
- 1位を特別扱いせず全参加者を同じ形式で表示

### 管理
- TOPと同じデザインシステムへ統一
- 勝負設定
- 参加者追加 / 編集 / 削除 / 勝負服
- レース追加 / 詳細 / 編集 / 削除
- 勝負削除

### 詳細・入力
- 参加者詳細（馬柱）、レース詳細、デジタル馬券も共通デザインへ統一
- 既存のスマホ向け入力フォーム最適化を維持

## Supabase

データ構造はv4.0から変更していません。
既存利用者は `supabase-setup.sql` の再実行不要です。
