# Horse Bet Battle v4.0

GitHub Pages + Supabase で動作する、競馬馬券勝負の共有アプリです。

## v4.0 デザイン刷新

基準デザインを「競馬場の情報盤 × 大人向けスポーツアプリ」に変更しました。

- 最大払戻額ランキング：着順掲示板スタイル
- 全レース一覧：レーシングプログラム / 出馬表スタイル
- 参加者：勝負服カラー・柄を一貫して表示
- 回収率：情報盤の数値パネル
- 直近レース結果：払戻額順のコンパクト表示
- デジタル馬券：紙券をモチーフにした詳細表示
- PC：複数カラムの情報端末型レイアウト
- スマホ：同じ情報を縦に再配置して操作性を維持
- 全入力フォーム：スマホ向けの16px以上の入力文字、スクロール可能モーダル、保存操作の到達性を維持
- 大会管理：表画面から分離

## 更新方法

ZIPを展開し、GitHub `keiba` リポジトリ直下の同名ファイルを上書きしてください。

Supabaseのデータ構造はv3.0から変更していないため、既存利用者は `supabase-setup.sql` の再実行は不要です。

## ファイル

- `index.html` — アプリのHTML入口
- `style.css` — UIデザイン
- `app.js` — 画面描画、計算、Supabase読み書き
- `config.js` — Supabase接続設定
- `supabase-setup.sql` — 初期DB設定
- `README.md` — この説明書
