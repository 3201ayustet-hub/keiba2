# KEIBA QUIZ

GitHub Pages向けの静的Webアプリです。

## 構成
- index.html
- style.css
- app.js
- questions.json
- final_races.json
- manifest.json
- icon-180.png
- icon-512.png

問題を増やす場合は `questions.json`、FINAL問題を増やす場合は `final_races.json` に追加してください。

通常問題は5問固定。正解1問ごとにFINALヒントが1段階開き、不正解では進みません。
FINALの答えは1着馬名のみです。
