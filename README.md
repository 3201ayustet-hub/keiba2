# Horse Bet Battle v4.2

v4.1の見やすさを維持しながら、全画面のデザイン言語と勝負服機能を強化した版です。

## 主な変更
- 勝負服を四角アイコンから騎手ジャケット型SVGへ変更
- 胴色 / 袖色 / 柄色を自由設定
- 胴柄：無地 / 一本輪 / 二本輪 / 縦縞 / たすき / 市松 / 山形
- 袖柄：無地 / 一本輪 / 二本輪 / 縦切替
- 管理画面で大サイズ + 実使用サイズをリアルタイムプレビュー
- クイックカラー12色
- 勝負服はTOP / 回収率 / 順位推移 / 馬柱 / 馬券 / 管理画面で共通表示
- トップタイトルをRACE MEETING風へ統一
- 勝負一覧も同じレーシングプログラム風へ変更
- フォントをSans / Monospace / 着順Serifの3系統へ統一

## Supabase
DBテーブル構造は変更していません。
勝負服の追加情報も既存のJSONへ保存されるため、SQLの再実行は不要です。
