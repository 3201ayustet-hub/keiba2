# Horse Bet Battle v3.0

競馬馬券勝負を仲間内で共有するWebアプリです。GitHub Pages + Supabaseで動作します。

## v3.0 の主な変更

- 大会トップを「開催情報ボード」風に再設計
- 最大払戻額を「着順掲示板」風に整理
- 参加者ごとの勝負服カラー・柄を追加
- 勝負服カラーをランキング・順位推移・個人成績・馬券に連動
- レース一覧を「RACE PROGRAM / 出馬表」風の高密度リストに変更
- 個人成績を「FORM GUIDE / 馬柱」風に変更
- レース履歴からオリジナルのデジタル馬券を表示
- 5,000円権 / G1以外権をチケット風に整理
- ルール・賞品を「開催要項」風に表示
- 大会管理を表画面から分離し、参加者追加・勝負服設定などを管理画面へ集約
- 既存のSupabase共有、順位推移、スマホ最適化フォームを維持

## ファイル

- `index.html` : 画面の入口
- `style.css` : UI・競馬デザイン
- `app.js` : 集計・保存・画面操作・順位推移・馬券生成
- `config.js` : Supabase接続情報
- `supabase-setup.sql` : Supabase初期設定SQL
- `README.md` : この説明書

## 更新方法

既存のGitHubリポジトリ上の同名ファイルを、このフォルダのファイルで上書きしてください。

Supabaseのテーブル構造はv2.xから変更していません。既に動作している場合、`supabase-setup.sql` の再実行は不要です。

## 管理画面

勝負トップ右上の `•••` から「大会管理」に入れます。

管理画面では以下を操作できます。

- 勝負名・期間・ルール・賞品の編集
- 参加者追加
- 参加者名変更
- 勝負服カラー・柄の変更
- 参加者削除
- 勝負削除

レース追加はトップの `＋`、レース編集・削除は各レース詳細から行います。

## 勝負服

既存参加者にも自動で勝負服が割り当てられます。設定を保存するとSupabaseの共有データ内に保持され、他端末でも同じ色・柄になります。
